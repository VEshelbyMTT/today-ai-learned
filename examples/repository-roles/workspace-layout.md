# Workspace Layout Example

Use this as a starting point for a VS Code workspace that contains several sources with different responsibilities.

```text
Workspace

Personal area
    Learning notes
    Drafts
    Experiments

Repository area
    Team codebase
        Current implementation
    Architecture repository
        Decisions and proposed direction
    Knowledge repository
        Reviewed guidance and runbooks
    External references
        Examples only
```

## Questions to answer

1. Which source describes current behaviour?
2. Which source owns proposed direction?
3. Where should reusable guidance be written?
4. Which sources are examples rather than authority?
5. What should the agent do when two sources disagree?
6. Which local material must never be published?
