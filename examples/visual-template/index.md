# Weekly Visual Template

Use this SVG to create another Today AI Learned issue while keeping the same cream, cyan, green, and black visual language.

<img class="article-hero" src="{{ '/examples/visual-template/today-ai-learned-weekly-template.svg' | relative_url }}" alt="Today AI Learned weekly visual template with date and subject placeholders">

## Edit the template

1. Download the SVG source.
2. Replace `{YYYY-MM-DD}` with the publication date.
3. Replace `{SUBJECT}` with the issue subject.
4. Export a PNG if the publishing platform requires a raster image.
5. Check that the longest subject fits before publishing.
